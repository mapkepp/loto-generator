# Управление кухонным светом при включённом VPN — iOS 26.6.2

Здесь находятся **экспериментальные** команды Apple Shortcuts с автоматическим управлением VPN. Исходные команды, без автоматического переключения VPN, оставлены без изменений.

### Файлы

- [Kitchen_AutoVPN_ON.shortcut](./Kitchen_AutoVPN_ON.shortcut) — включить свет.
- [Kitchen_AutoVPN_OFF.shortcut](./Kitchen_AutoVPN_OFF.shortcut) — выключить свет.
- [Kitchen_AutoVPN_RESTORE.shortcut](./Kitchen_AutoVPN_RESTORE.shortcut) — снова подключить VPN вручную, если автоматическое восстановление не удалось.

Все три файла имеют подпись Apple-формата AEA1. **Токен Яндекса в них отсутствует**.

### Алгоритм включения и выключения

1. Сохранённый при импорте OAuth-токен передаётся в заголовке Authorization с префиксом Bearer.
2. Штатное действие **Set VPN → Disconnect** временно выключает выбранный VPN-профиль.
3. Пауза 2 секунды.
4. HTTPS POST запрос к `https://api.iot.yandex.net/v1.0/devices/actions` с корректным JSON и идентификатором устройства.
5. Действие **Set VPN → Connect** включает прежний профиль VPN.
6. Пауза 2 секунды.

**ВАЖНО:** во время шага 2–5 VPN действительно **отключён**, поэтому это не полноценная маршрутизация вне VPN с сохранением постоянно подключённого туннеля. В случае сбоя запроса или завершения команды до шага 5 VPN может остаться отключённым. Команды не определяют первоначальное состояние VPN, поэтому после успешного выполнения принудительно его включают. Если в VPN включено авто-подключение/on-demand, оно может мешать временному отключению.

### Установка на iPhone

1. Открыть ссылку из публичного репозитория через Safari, скачать файл и открыть через Apple «Команды».
2. Ввести **новый** OAuth-токен Яндекса без префикса Bearer при импорте.
3. В редакторе команды выбрать **один и тот же установленный VPN-профиль AmneziaVPN** в **обоих** действиях «Настроить VPN» (**Disconnect** и **Connect**). Профиль умышленно не закреплён в файле: его нельзя корректно назначить без доступа к VPN-конфигурациям данного iPhone.
4. Для аварийной команды отдельно выбрать профиль AmneziaVPN в единственном действии «Настроить VPN → Подключить».
5. Запускать новую команду **с включённым VPN**, затем проверить, что лампа среагировала и VPN снова подключился.

Существующая интеграция AmneziaVPN с системным действием Set VPN для конкретного VPN-протокола не подтверждена на реальном устройстве. Если профиль недоступен для выбора, этот метод применить нельзя.
