# Яндекс Умный дом при постоянно включённом VPN — iPhone iOS 26

**Цель:** сохранить VPN подключённым, а запросы к `api.iot.yandex.net` направлять напрямую, без стороннего прокси и публикации OAuth-токена.

## Выбор правильного режима AmneziaVPN

**Не меняйте текущий режим раздельного туннелирования, не проверив его.**

### Вариант А — «Только адреса из списка должны открываться через VPN» (рекомендуемый)

Это предпочтительная архитектура: лишь выбранные заблокированные ресурсы идут через VPN, всё остальное (включая Яндекс) — напрямую. **В этом режиме не импортируйте наш файл исключения:** список означает обратное (IP из списка через VPN).

Проверьте, что `api.iot.yandex.net`, IPv4 `213.180.193.211` и охватывающие его IP-подсети не попали в перечень VPN-маршрутов. Если попали — требуется корректировка включающих подсетей с сохранением остальных правил.

### Вариант Б — «Адреса из списка не должны открываться через VPN»

**Только если у вас уже используется этот режим** (весь остальной интернет через VPN), можно импортировать готовый файл [Yandex_Smart_Home_DIRECT_AmneziaVPN.json](./Yandex_Smart_Home_DIRECT_AmneziaVPN.json) — ровно одно IPv4-исключение `213.180.193.211/32`.

Откройте AmneziaVPN → Раздельное туннелирование → По сайтам/IP → **⋮ → Импортировать → Добавить к существующим**. Не выбирайте «Заменить список»! Включите правило и при необходимости переподключите VPN **один раз для применения настроек**. Для каждого нажатия на команду VPN отключать не нужно.

## Работа команд

Установленные подписанные `Kitchen_Light_ON.shortcut` и `Kitchen_Light_OFF.shortcut` не требуется изменять только из-за VPN: они отправляют HTTPS-запрос на Яндекс. Решение о маршруте принимает iOS/VPN. OAuth-токен остаётся локально в командах и не публикуется в репозитории.

## Ограничения / тестирование

- На 22.10.2026 DNS Google и Cloudflare вернул `api.iot.yandex.net → 213.180.193.211` (A); присутствует также IPv6 `2a02:6b8::1c2` (AAAA). Записи могут измениться, IPv4-исключение нужно обновлять по мере необходимости.
- **AmneziaVPN поддерживает IPv4, но не IPv6 в split tunneling**, поэтому выбранный iPhone IPv6-маршрут может обойти IPv4-исключение. Работа на реальном телефоне и включение лампы — **NOT_TESTED**.
- Для Amnezia Free и отдельных клиентов AmneziaWG возможности могут отличаться. Если используется другое VPN-приложение, правила AmneziaVPN не применимы.
- Не заменяйте HTTPS на HTTP и не обращайтесь к IPv4-адресу вместо доменного имени без корректного TLS. Не загружайте OAuth-токен на GitHub.
