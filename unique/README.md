# Уникальные карточки Русского лото — отдельная версия

**Открыть:** https://mapkepp.github.io/loto-generator/unique/

**Обычный генератор (не изменён):** https://mapkepp.github.io/loto-generator/

Это отдельная страница, независимая от старой версии. Исходная `index.html` старого генератора и его PDF-алгоритм не изменены.

## Гарантии внутри одного созданного PDF

1. Все карточки различаются: перед принятием каждой карточки проверяется подпись полной сетки 3×9, включающая размещение и значения чисел.
2. Каждая карточка содержит 15 разных чисел: 3 строки по 5, 9 столбцов, верные интервалы 1–9, 10–19, ..., 80–90. Числа сверху вниз в каждом столбце идут по возрастанию.
3. Каждые шесть подряд идущих карточек используют **все числа от 1 до 90 ровно один раз**. Карточки организованы в шестёрки.
4. Частота любого числа по **всему файлу** отличается от частоты любого другого числа не более чем на 1. Например, для 24 карточек все 90 чисел встречаются ровно 4 раза.
5. Любая ошибка проверки останавливает генерацию — не выдаётся PDF с недоказанным балансом или повторами.

**Важно:** числовые значения могут повторяться на разных карточках **из разных шестёрок** — это необходимо при тиражах больше шести карточек. Не повторяются полные карточки в пределах **одного PDF**.

Гарантия уникальности **не распространяется на отдельные запуски**: генератор не хранит созданные комбинации и не сравнивает новые файлы с ранее скачанными. Для повторной печати того же комплекта сохраняйте исходный PDF. Нельзя восстановить предыдущие наборы по дате или настройкам.

## Надёжность и безопасность

- Вместо рекурсивного повторения целой карточки — конечный алгоритм баланса; назначение строк ограничено 9 колонками, без бесконечной генерации.
- Для возможных совпадений с уже принятыми карточками допускается до 64 попыток заново собрать шестёрку, затем выдаётся понятная ошибка.
- Граничное значение — не больше 200 страниц А4 за запуск и не больше 3000 карточек в ядре генерации (фактический предел ниже из-за числа страниц). Ввод контролируется до создания PDF.
- На странице отображается прогресс подготовки PDF и выдаётся повторная ссылка на скачивание.
- Генерация полностью в браузере пользователя; для создания карточек нет сервера, регистрации или отправки данных в базу. Библиотека pdf-lib загружается с CDN, как на исходной странице.
- Удобные настройки ширины, высоты, шрифтов, линий, интервала между карточками и нижних меток сохранены. Ширина карточки ограничена печатным полем А4.
- Пожертвования добровольны и не дают привилегий: [ЮMoney](https://yoomoney.ru/fundraise/1L2T11QBAHF.261022), [Т-Банк](https://t.tb.ru/pm_short/7Ixu10XDRWa).

## Алгоритм

`unique-engine.js`: распределение слотов в каждой шестёрке карточек с точными квотами по девяти диапазонам чисел; баланс числа слотов по строкам; случайная перестановка чисел каждого диапазона; проверка содержимого 3×9, глобальной уникальности и равномерности появления 1–90.

`unique-app.js`: ввод/валидация параметров, раскладка карточек на А4, отрисовка pdf-lib, индикация статуса, скачивание.

`index.html`: копия пользовательской формы с отдельными CSS/SEO, ссылками на оригинал и отдельным разделом объяснений.

## Регрессионные проверки

Запустить локально или в GitHub Actions, при установленном Node.js:

```bash
node unique/unique-engine.test.js
```

Тесты покрывают от 1 до 3000 карточек, 100 разных последовательностей случайных чисел по 600 карточек, отсутствие дублей, валидность каждой сетки, абсолютный баланс 1–90 на шестёрку и отклонение частот не более 1.

Дополнительно проверено тестовым PDF-движком: 1, 6 и 200 страниц, отрисовка карточек, сигнал об ошибке при невалидном вводе или отсутствии библиотеки PDF. **Фактическое скачивание настоящего PDF в браузере / на физическом принтере — NOT_TESTED** до отдельной реальной проверки.

Изменения этой отдельной версии никогда не должны автоматически переноситься в старый `/index.html`: сначала отдельное согласование и регрессии.
